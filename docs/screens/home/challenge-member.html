Challenge → tap a member

Flutter pushes a full-screen page titled “Statistics” — avatar + name + total, then a flat per-day list grouped by month, and nothing else (rank is commented out, no actions). Native currently does nothing on tap; its MemberDetailSheet was built to that same spec and never wired up. Three designs below, all fed by the same two calls Flutter already uses (/members/{id} + /members/{uid}/workout-stats).
The Workout switch drives every mock: a steps challenge (WLS, auto-tracked, unit STEPS) vs a rep challenge (PUSHP, camera-counted, unit TIMES). V1 carries a diff panel spelling out what stays / is replaced / is added. Note: the wire has no goal or target field on either type — POST /challenge never takes one — so the old “% of goal” bar was fabricated; it now measures against the leader, which is real data.
