Chat PIN — small dialog

A small centred dialog (the same shell as the app's other popups) replaces the tall bottom sheet for the E2EE chat-key backup PIN. Digits come from the phone's own number keyboard — no custom keypad — so the dialog stays compact and sits just above the keyboard. The title reads “Update chat PIN” when a PIN already exists. 4–8 digits. Type with your keyboard or tap the number pad; the switch jumps to any case.
